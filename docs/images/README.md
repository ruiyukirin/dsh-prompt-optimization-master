# 截图目录

README 里引用的图片放这里。**目前是空的**——需要一张真实截图。

## 需要什么

| 文件名 | 内容 | 怎么拍 |
|---|---|---|
| `composer-button.png` | 输入框工具栏，能看到 ✨ 按钮（在模型选择器左边） | 在输入框里打几个字让按钮出现，然后截取输入框那一条 |
| `settings-panel.png` | 右键 ✨ 后弹出的设置面板 | 打字 → 右键 ✨ → 截图 |

## 要求

- **PNG 格式**，宽度建议 800–1200 像素（够看清就行，别太大）
- **不要包含聊天内容**——只截输入框区域，避免泄露对话
- 深色/浅色主题都可以

## 怎么截图（Windows）

1. `Win + Shift + S` 进入截图模式，框选输入框那一条
2. 图会自动进剪贴板
3. 打开画图粘贴，另存为 PNG 到这个目录
4. 告诉我，我把 README 里的图片引用接上

> 之所以要你拍：我这边拿不到浏览器画面，而"假装有截图"是不行的——那属于编造。
