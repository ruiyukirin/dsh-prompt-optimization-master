## 2026-10-25 备注

- **周/月下载与昨天完全一致**：不是"没人装"，而是 npm 的统计窗口两天没往前走
  （两天查询的窗口都是 `2026-10-16 ~ 2026-10-22` 与 `2026-09-23 ~ 2026-10-22`）。
  npm 的下载统计约滞后 2–3 天。
- **目录已更新到 0.3.3**：昨天预测"站点重建约 1 天"，准时生效。
  条目数一天内从 6,704 涨到 6,896（+192），所以排名从 2851 微滑到 2855 是
  "新插件涌入"而不是"你退步"——比例从后 16.8% 变后 17.4%。
- **逐日数据不可靠**：`2026-10-13 ~ 10-15`、`10-19 ~ 10-21` 全是 0，
  但 `10-18` 一天 218。真实的自然用户不会这样分布。结论：日粒度存在聚合/去重
  口径问题，**只用周和月判断趋势**。

## 采集命令

```powershell
# 周/月滚动（注意看返回的 start/end，窗口不变则数字不会变）
Invoke-RestMethod "https://api.npmjs.org/downloads/point/last-week/dsh-prompt-optimization-master"
Invoke-RestMethod "https://api.npmjs.org/downloads/point/last-month/dsh-prompt-optimization-master"

# 逐日（仅供看发布日台阶，不做趋势判断）
(Invoke-WebRequest "https://api.npmjs.org/downloads/range/2026-09-23:2026-10-25/dsh-prompt-optimization-master" -UseBasicParsing).Content

# 目录条目与排名
$j = Invoke-RestMethod "https://awesome-dsh-plugin.com/plugins.json" -TimeoutSec 120
$e = $j.plugins | Where-Object { $_.name -eq 'dsh-prompt-optimization-master' }
$e | Select-Object version, stars, downloads, downloadsStart, downloadsEnd
```
